# 清水 # 什 X 犬 # 布莱克 X 艾德里安 # by 黑黑
发表于 2025-06-20 分类于 文 ， 赛博群像 本文字数： 605 阅读时长 ≈ 2 分钟

[by 黑黑]

那是……

五层楼高的培养舱室里弥漫着淡淡的金属与化学药品的气味，粗大的营养管道和线缆布满了四周所有的墙壁，它们从屏蔽墙的深处延伸而出，和赤裸的躯体紧紧缠绕在一起，接入无数一模一样的“犬”的颈部，脊椎和胸口，淡红色的液体映照出他们苍白的脸庞，那些紧密排列的复制人被透明的舱体包裹着，柔顺的发丝像海藻一样飘荡在舱内，他们就像沉睡在子宫中的胚胎，双目闭合，表情平淡。

整个空间回荡着令人不安的嗡鸣声，饶是什也被这骇人的景象惊地愣在原地。

最下方的走廊上，听到动静的布莱克回过头，双方视线交错，不等男人脸上惊喜的神情完全打开，站在什身边的红发男人就像迅捷的猎豹一样爆冲而出，几乎是瞬间就来到了布莱克的面前——

好快！

毫无遮掩的杀意没有任何预兆地如同狂潮一般席卷而来，布莱克感觉自己的呼吸似乎都被无形的力量压制，他想要后退，甚至只是抬起手臂防御，但身体就像陷入泥沼，动作迟缓地令人绝望。不等布莱克做出反应，一股不容抗拒的力量猛地将他推开，男人踉跄地向后跌去，视线中，原本站在身后的艾德里安正横插在自己与红发男人之间。

在那样恐怖的爆发速度下，艾德里安挡在面前的动作更像是护主的本能，他膝盖微曲，整个人像一张紧绷的弓，双手死死握着犬的手腕，手指几乎要扣进另一人的皮肉。

布莱克看出艾德里埃在强撑着没有后退，他的宠物眼神凌厉而专注，嘴唇抿成一条直线，严肃警惕地看着这个和自己长得一模一样的人。

真正的“艾德里安”。

布莱克脸上的笑容不由自主地扩大，他从来没有如此近距离地感受到来自于对方的情绪，即便是愤怒也是如此鲜活而炽烈的让人欲望高涨。
